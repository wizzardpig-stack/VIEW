# VIEW

A full-screen ambient visual experience built around continuously evolving visual worlds. VIEW is designed to be watched rather than operated, with slow scene drift, atmospheric transitions, and a minimal control layer.

## Live

https://wizzardpig-stack.github.io/VIEW/

## What it demonstrates

- WebGL-driven ambient rendering with a CSS fallback path
- Full-screen mobile composition using dynamic viewport units
- Safe-area-aware controls for modern phones
- Coarse-pointer and short-viewport handling
- Reduced-motion support and lighter mobile visual effects

## Stack

HTML, CSS, vanilla JavaScript, WebGL and browser media APIs.

## Development approach

Independent concept development, interaction design, visual direction, iterative testing, performance tuning, and AI-assisted implementation. The current build is specifically hardened for iPhone-scale layouts.
